# Q3 v3 首轮模型与结果说明

本轮使用源码 `3f9e673`，首次完整运行 `q3v3-r1`。这是用户授权的暂定Q2依赖下的受限策略，非已完成全部依赖放行的正式版本。Q2零点原合同逐槽保留，未重新使用零点附件3预报优化原合同；因此本文仅评价后续发布时间信息的增量价值。

## 因果调整模型

计划日按附件5的144行对齐，物理窗口为00:10至次日00:10；附件端点仍有题意歧义，不能把该口径称为官方已经确认。06/12/18点分别确认[35,71)、[71,107)、[107,144)槽，每个交付段只确认一次。06点的最新完整实际观测为槽34，其余发布点类推。官方整点预报与最后完成槽的代理锚点作线性插值，转换为十分钟能量；代理锚点并非独立瞬时仪表读数。

负荷预测采用冻结Q2预测加最近12个已完成槽残差的中位数校正。风险候选使用最近28个成熟历史日的同发布时间残差65%分位数，评估门使用此前至多14个不同历史日，两池不重叠，各至少7日才启用。历史残差必须覆盖的目标窗口已完整结束。

定义原合同q0、增购u、减购r、最终购电q=q0+u-r、充电c、放电d、紧急电h、无收益剩余供给w及电量E。候选规划最小化调整费、预测紧急费和终端资产价值之和，满足：

```
q + pv + d + h = load + c + w
E_next = E + 0.9*c - d/0.9
1200 <= E <= 10800
0 <= c,d <= 5000/6
```

二元充电模式禁止充放电同时发生，也禁止紧急电直接或间接充电。主解释A的现金总费为 `sum(p*q0 + 1.5*p*u + 0.5*p*r + 5*p*h)`；B仅把减购项改为退款 `-0.5*p*r`。在A与免费放弃剩余供给的假设下，减购被保留原合同弱支配，因此A固定r=0；不能根据B更便宜而改选题意。

候选与保留合同在独立历史残差池上使用同一个逐槽反馈执行器评价，费用只计一次。候选平均成本更低才接受。该门是历史场景检验，不是对未来收益的确定保证。实际执行只读取当前区间测量，跨日维持本策略自身SOC，不注入Q2执行状态。

各策略期末SOC均为4,407.27 kWh。主策略相对保留合同节省479,766.73元（约3.42%），现金比较不存在本次期末电量差的干扰。主策略增购费用439,593.51元，紧急费用从962,374.12元降至43,013.89元；费用节省来自以计划调整降低高价紧急采购。

在预先声明的嵌套发布对照下，从仅06点增加12点更新后，样本费用进一步下降63,977.50元；再增加18点更新后下降95,922.18元。因此样本支持保留多个后续发布时间，并由经济门逐次决定是否交易。此结论是本组嵌套策略的差异，不是单个预报渠道的普适因果价值。

版本自身 `paired_comparison.csv` 给出的14日块Bootstrap主策略日均资产调整费用差区间：全期[-2431.48,-734.40]元，2-6月[-4189.95,-830.94]元，7-12月[-1511.13,-205.57]元。负值表示候选更低。7-12月已被观察，仍只作回顾性证据；Bootstrap不消除模型选择偏差，不能将这些区间写成对未来的保证。联合比较工具使用另一固定随机种子并报告现金节省方向，区间数字有抽样差异，论文统一引用版本自身表格。
