|附件标签|所属交付区间|自然日归属|

|6:00|5:50-6:00|当前日|
|6:10|6:00-6:10|当前日|

每日144个区间，145个储能边界。E[0]是真实0:00状态，E[144]是真实24:00状态。四小时块为[0,4)、[4,8)、[8,12)、[12,16)、[16,20)、[20,24)，各24槽。功率转换为区间电量时乘1/6小时。

## 2. 减购：CANCEL_ORIGINAL_CHARGE_THEN_PENALTY_50_V1

减购时，先取消被减部分对应的原购电费用，再按题目约定的违约计价基础收取50%违约费。禁止继续采用“原费全付再加50%”作为新主解释。

对一个交付槽、一次调整，设零点合同q0，最终普通购电q，增购u=max(q-q0,0)，减购r=max(q0-q,0)。原合同单价为p0，调整交易计价基础为p_adj，紧急实际结算价为p_em，紧急电量h，则：

```
C = p0*(q0-r) + 1.5*p_adj*u + 0.5*p_adj*r + 5*p_em*h
```

这一区分保留了三个价格各自的角色，不把“确认退款规则”误当作“确认所有价格都相同”。若三者恰为同一p，可化为：

```
C = p*q0 + 1.5*p*u - 0.5*p*r + 5*p*h
```

同价1元/kWh、没有紧急电的例子：

|原计划|调整后|保留原购电费|增购费|违约费|总普通费用|
|---:|---:|---:|---:|---:|---:|
|100|80|80|0|10|90|
|100|0|0|0|50|50|
|100|120|100|30|0|130|

旧结算B在同一交付价计全部费用的假设下，与上述简化式一致；它只能作为历史对照，不能证明交易价格时点或新时间口径已经正确。旧结算A下“减购被保留原合同弱支配”的结论不再适用于新主规则，后续优化器不能继续固定减购r=0。

原合同价格与交易时刻价格如何对应，尤其Q4何时可见报价、何时确定结算价，仍待确认。重复修订是逐笔收费还是最终相对原计划净额收费，也尚未确认；上述单次调整公式不自动赋予任何一种重复计费规则。
