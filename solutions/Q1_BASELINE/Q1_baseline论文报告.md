# 问题一 Baseline 论文报告：确定性微网购电—储能联合优化

> 用途：本文件是问题一的论文手输入稿，用于后续整篇论文的模型建立、求解结果与验证章节。本文只陈述问题一已经获得的确定性结果，不外推问题二至问题四的年度表现。

## 1. 问题一的任务与建模目标

问题一给出一个计划日内每个10分钟时段的小区负荷功率、光伏预测功率和外部电网电价。微网需要在满足小区用电需求和储能运行约束的前提下，于计划开始时一次性确定144个时段的普通购电量，使全天普通购电费用最小。

这一问题具有三个鲜明特征：第一，负荷、光伏与价格均已确定，不涉及预测误差；第二，储能会把不同时段连接起来，当前充电会改变后续可放电量；第三，外部购电、光伏消纳和储能动作需要逐时段满足能量守恒。因此，问题一适合建模为带储能状态递推的确定性线性规划，并以充放电互斥模型作为物理一致性核查。

问题一同时承担整题的基础验证作用。后续问题虽然会增加预测误差、滚动更新、合同调整和波动价格，但能量平衡、储能效率、容量边界和功率边界均沿用本问题的物理内核。

## 2. 时间口径：必须固定的硬规则

本题最容易发生系统性错误的地方不是优化公式，而是144个时段的先后顺序。本文采用以下唯一时间口径：

1. 每个计划日共有144个10分钟决策段，严格按照附件和结果模板的行顺序排列。
2. 第1段为计划日当天的`00:10—00:20`。
3. 随后每段向后推进10分钟；`23:50—次日00:00`之后，最后一段为`次日00:00—00:10`。
4. 最后一段明确属于第二天的自然时钟，但仍属于前一个计划日的第144个决策段。
5. 下一计划日从该日的`00:10—00:20`继续，因此两个计划日之间既不重复，也不存在额外整体后移。
6. 题目指定的`10:00—10:10`、`12:00—12:10`等时段，直接按结果模板的字面标签定位，禁止再向前或向后平移一行。

因此，计划序列的真实边界为当天00:10至次日00:10。储能状态共有145个边界值：第一个状态位于当天00:10，第145个状态位于次日00:10。官方结果模板仍使用“0:00储电量”“24:00储电量”以及“0:00—4:00”等组名；本文保留模板名称，但在数据处理和程序日志中同时保存真实序列边界，避免模板组名反向改变144段数据顺序。

六个四小时汇总均由连续24个决策段组成，其真实序列覆盖分别为：

| 模板组名 | 连续决策段的实际覆盖 |
|---|---|
| 0:00—4:00 | 当日00:10—04:10 |
| 4:00—8:00 | 当日04:10—08:10 |
| 8:00—12:00 | 当日08:10—12:10 |
| 12:00—16:00 | 当日12:10—16:10 |
| 16:00—20:00 | 当日16:10—20:10 |
| 20:00—24:00 | 当日20:10—次日00:10 |

上述10分钟命名差异只影响时间解释和指定时段索引，不改变144维优化向量的先后顺序、全天购电总量和总费用。

## 3. 数据处理与单位统一

附件1包含144行数据，每行依次给出时间、电价、小区负荷功率和光伏预测功率。电价单位为元/kWh，负荷与光伏单位为kW。由于优化模型处理的是每个10分钟区间内的电量，需要先进行功率—电量转换。

记时段长度为

\[
\Delta t=\frac{10}{60}=\frac{1}{6}\ \mathrm{h}.
\]

对第 \(t\) 个时段，负荷电量与光伏可用电量分别为

\[
l_t=P^L_t\Delta t,\qquad v_t=P^V_t\Delta t,
\]

其中 \(P^L_t\) 和 \(P^V_t\) 的单位为kW，转换后的 \(l_t\) 与 \(v_t\) 单位为kWh。模型中的普通购电量、充电量、放电量、剩余供给量和储电量均统一使用kWh，从而保证能量平衡式量纲一致。

数据读入后依次检查了行数、缺失值、非负性和时间顺序。附件1恰有144个有效时段，价格、负荷和光伏数据均无缺失，并与result1模板的144个计划购电位置逐项对应。

## 4. 模型假设

为使问题一形成可解且可核验的确定性基线，作如下假设：

1. 附件1中的负荷、光伏预测和电价在问题一中均视为确定量。
2. 微网不能向外部电网售电，多余供给不产生收益；多余部分统一记为“剩余供给”，不无条件称为弃光。
3. 储能额定容量为12000 kWh，允许储电范围为额定容量的10%至90%，即1200—10800 kWh。
4. 充电效率和放电效率均取0.9，往返效率为0.81。
5. 储能最大充放电功率为5000 kW，对应每个10分钟时段的最大充电量或放电量为 \(5000/6=833.333333\) kWh。
6. 计划序列起点和终点的储电量均为6000 kWh，以避免通过透支期末电量获得虚假的费用优势。
7. 问题一不设置紧急购电，全部负荷由普通购电、光伏和储能放电共同满足。

## 5. 决策变量与模型架构

对每个时段 \(t=1,2,\ldots,144\)，定义：

- \(q_t\)：从外部电网计划购买的普通电量，单位kWh；
- \(c_t\)：从交流母线送入储能装置的充电量，单位kWh；
- \(d_t\)：储能装置向交流母线释放的放电量，单位kWh；
- \(w_t\)：负荷和充电均无法吸收的剩余供给量，单位kWh；
- \(E_t\)：第 \(t\) 个边界处的储电量，单位kWh，共有145个边界状态。

模型的计算架构可概括为：

附件1的价格、负荷和光伏功率 → 时间排序与功率转电量 → 构造逐时段能量平衡 → 加入储能状态递推及边界 → 求解确定性LP → 核查充放电互斥 → 复算费用和储量轨迹 → 写入result1模板并回读。

这一架构将“经济决策”和“物理执行”统一在同一个模型中。购电量决定直接现金支出；充放电量决定电能在不同时段之间的转移；状态变量保证所有储能动作在时间上可实现；剩余供给变量保证光伏过剩或已购电未使用时模型仍保持可行。

## 6. 数学模型

### 6.1 目标函数

记 \(p_t\) 为第 \(t\) 个时段的电价，则全天购电费用为

\[
C=\sum_{t=1}^{144}p_tq_t.
\]

问题一的优化目标为

\[
\min C=\min\sum_{t=1}^{144}p_tq_t.
\]

### 6.2 时段能量平衡

每个10分钟时段均满足

\[
q_t+v_t+d_t=l_t+c_t+w_t.
\]

等式左侧为该时段可供使用的普通购电、光伏和储能放电，右侧为小区负荷、储能充电以及无法利用的剩余供给。该式保证每个时段都不存在无来源电量或未记账缺口。

### 6.3 储能状态递推

考虑充放电损耗，储电量满足

\[
E_{t+1}=E_t+\eta_c c_t-\frac{d_t}{\eta_d},
\]

其中 \(\eta_c=\eta_d=0.9\)。充入母线侧电量 \(c_t\) 后，真正进入电池的能量为 \(0.9c_t\)；母线侧输出 \(d_t\) 时，电池内部需要减少 \(d_t/0.9\)。

### 6.4 容量、功率和非负约束

\[
1200\le E_t\le10800,
\]

\[
0\le c_t\le\frac{5000}{6},\qquad
0\le d_t\le\frac{5000}{6},
\]

\[
q_t,c_t,d_t,w_t\ge0.
\]

初末状态约束为

\[
E_0=6000,\qquad E_{144}=6000.
\]

### 6.5 充放电互斥核查

严格互斥模型可引入二元变量 \(z_t\)：

\[
c_t\le\frac{5000}{6}z_t,\qquad
d_t\le\frac{5000}{6}(1-z_t),\qquad z_t\in\{0,1\}.
\]

本实例首先求解上述模型的线性规划松弛。所得LP最优解在全部144个时段均没有同时充电和放电，因此可逐段构造二元变量：充电时取 \(z_t=1\)，放电时取 \(z_t=0\)，无动作时任取0或1。由此，LP最优解本身也是互斥MILP的可行解。

另一方面，MILP可行域是LP松弛可行域的子集，因此LP最优费用是MILP最优费用的下界；当前LP解又提供了同一费用的MILP可行上界。上下界相等，故可严格判定本实例的MILP最优费用与LP最优费用相同。该结论只适用于本次数据，不代表所有价格和约束条件下LP与MILP都等价。

## 7. 求解技术与实现流程

模型使用Python实现，并调用SciPy的HiGHS线性规划求解器。实现过程如下：

1. 读取附件1并核对144个时段；
2. 将负荷和光伏功率乘以1/6小时，统一转换为kWh；
3. 按变量组装目标向量、288条能量平衡与状态递推等式，以及变量上下界；
4. 使用HiGHS求解确定性LP；
5. 从解向量中恢复144段购电、充电、放电、剩余供给和145个储能状态；
6. 独立重算购电费用、能量平衡残差和储能递推残差；
7. 检查所有流量非负、储量在安全区间、充放电不超过功率限制且不存在同时充放电；
8. 将144段计划购电量、六个连续四小时块的充放电量及首末储量写入result1模板；
9. 重新打开输出工作簿，核对工作表、行列顺序、全部写入值和聚合结果。

由于问题一是线性且规模较小，使用确定性优化比遗传算法、粒子群等启发式算法更合适。线性规划能够直接给出全局最优解和明确的可行性状态，也便于逐条复查约束，不需要引入随机种子和收敛曲线。

## 8. 求解结果

### 8.1 指定时段购电量

以下结果直接按照result1工作表的字面时段标签读取，未进行任何额外平移。

| 指定时段 | 计划购电量/kWh |
|---|---:|
| 10:00—10:10 | 0.000000 |
| 12:00—12:10 | 486.402900 |
| 14:00—14:10 | 0.000000 |
| 16:00—16:10 | 394.931483 |
| 18:00—18:10 | 636.982617 |
| 20:00—20:10 | 0.000000 |

在10:00、14:00和20:00对应时段，模型没有安排外部购电；在12:00、16:00和18:00对应时段，模型根据当时净负荷、价格和储能状态安排了不同规模的购电。单个时段是否购电不能只由当时价格决定，还受到此前充放电形成的储量状态以及后续高价时段需求的共同影响。

### 8.2 全天购电量与费用

最优计划的全天普通购电量为

\[
Q_{\mathrm{grid}}=59482.698998\ \mathrm{kWh},
\]

对应购电费用为

\[
C^*=35126.948589\ \mathrm{元}.
\]

在相同负荷、光伏和价格数据下，若不配置储能，各时段仅用外部购电弥补正净负荷，费用为48052.046591元。因此，储能优化使该计划日费用减少12925.098002元，降幅为26.8981%。这一降幅仅说明附件1所代表的确定性典型日，不应直接外推为全年节约率。

| 模板组名 | 实际连续覆盖 | 充电量/kWh | 放电量/kWh |

| 4:00—8:00 | 04:10—08:10 | 833.333333 | 6365.841200 |
| 8:00—12:00 | 08:10—12:10 | 4787.964288 | 1702.996983 |
| 12:00—16:00 | 12:10—16:10 | 5286.035177 | 91.101383 |

储能在不同时间块中呈现明显的跨时转移特征：低价或光伏富余阶段主要充电，高价或净负荷较高阶段主要放电。由于充放电效率小于1，全天充电量与放电量不会简单相等；真正满足闭环的是考虑效率后的储量递推，并且计划序列起末储量均为6000 kWh。

## 10. Baseline的作用与后续接口

问题一的主要价值不仅是得到一个典型日最优费用，更是建立整题统一的物理与计算基线：

1. 固定10分钟离散尺度以及kW到kWh的转换方式；
2. 固定逐时段能量平衡和含效率的储能状态方程；
3. 固定储能容量、安全范围、充放电功率和互斥要求；
4. 建立独立费用复算和Excel回读流程；
5. 为问题二提供确定性计划器，但问题二必须加入因果预测、预测残差风险余量、跨日真实储量传递和应急购电账本。

后续模型不能直接把问题一的确定性费用当作年度运行费用，也不能把问题一的未来已知信息权限带入问题二。问题一解决的是“在给定一天全部确定输入时如何实现最低购电费”，而问题二开始解决“仅凭当时可获得信息如何制定可执行计划”。

## 11. 模型优点与局限

模型的优点包括：物理含义清晰、全部约束线性、可得到全局最优解；储能状态完整连接144个时段；费用、平衡、互斥和模板输出均可独立复核；模型结构能够直接复用于后续问题。

模型的局限包括：问题一把负荷、光伏和价格视为完全确定，尚未描述预测误差；未考虑电池老化成本和循环寿命；剩余供给不产生售电收益；LP与互斥MILP同值只对当前实例成立；官方模板的时间组名与实际计划序列存在10分钟命名差异，后续任何数据拼接、作图和论文表格都必须继续遵守本文的时间硬规则。

## 12. 可供正文直接改写的结论段

针对问题一，本文建立了以10分钟为时间尺度的微网购电—储能联合调度模型。模型首先将附件中的负荷和光伏功率转换为区间电量，再以普通购电费用最小为目标，通过逐时段能量平衡、储能效率递推、容量边界和功率边界连接全天144个决策段。线性规划得到的最优解在全部时段天然满足充放电互斥，因此其费用同时构成互斥混合整数模型的严格最优值。计算得到全天计划购电量为59482.698998 kWh，购电费用为35126.948589元；相较无储能情形的48052.046591元，费用降低26.8981%。最大能量平衡残差和储量递推残差分别为2.27×10^-13 kWh和8.31×10^-13 kWh，储电量始终处于1200—10800 kWh安全范围内，且序列起末储量均为6000 kWh，说明所得方案满足经济性与物理可执行性要求。

## 13. 论文手使用提示

- 摘要和结论可引用全天购电量、费用、无储能对照、降幅及两项最大残差。
- 指定六时段必须使用第8.1节按模板字面标签读取的数值，不使用旧摘要文件中曾按右端点解释得到的平移数值。
- 作图时横轴应从当日00:10开始，最后一个区间明确标记为“次日00:00—00:10”；不可把最后一段画到同日零点之前。
- 储能汇总表应同时保留模板组名和实际连续覆盖，避免评阅人误认为数据漏掉或重复了10分钟。
- 不把剩余供给全部称为弃光，不把26.8981%外推成全年节约率，不把本实例LP/MILP同值写成一般定理。
