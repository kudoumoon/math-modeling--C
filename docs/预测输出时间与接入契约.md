# 预测输出时间与接入契约

本说明于2026-09-13统一当前预测器的实际解释。原题对附件3只规定“未来24小时整点的光伏发电功率预报”，没有定义小时平均窗口；以下展开是明确的建模近似，不冒称题目原文。

## 时间与单位

- 附件日行与模板位置不变：第1槽为00:10-00:20，第144槽为次日00:00-00:10。
- PV采用“移位小时块平均近似”：发布时刻t的第h小时预报，表示从t+(h-1)小时+10分钟到t+h小时+10分钟的六个十分钟槽的平均功率，每槽同值。功率kW乘1/6小时得到每槽kWh，六槽总能量等于该预报功率乘1小时。
- 例如零点发布的第1小时预测为60kW，则00:10、00:20、00:30、00:40、00:50、01:00开始的六段各10kWh，共60kWh；真实标签是对应六段功率均值，到01:10才可用于训练或校准。
- 零点发布第24小时覆盖23:10至次日00:10。18点发布第7小时覆盖次日00:10至01:10，始终保留本次18点发布身份。
- 这是与附件槽位一致的移位近似，与主规约历史4.2中未移位的“(h-1,h]内六段”表述存在10分钟差异。本轮明确采用本说明的解释，不改动冻结主规约及其hash。未来若采用整点点值插值，应新增独立敏感性实验，不能混用旧标签或旧收益。

## 优化器读取的CSV

`causal_forecasts.csv`不含实际标签。唯一键为`target_name, issue_time, target_time`。每日负荷和价格各144条，PV每次发布24条，每日96条；数据年末之后没有真值的PV请求仍输出。

|字段|含义|
|---|---|
|target_name|load_10min、price_10min、pv_hourly|
|issue_time|本条预测的决策/发布时间|
|target_time|负荷/价格区间起点；PV官方整点目标标签，不用它反推移位窗口|
|interval_start、interval_end|预测实际覆盖的起止时刻，左闭右开|
|completed_at|全部真实标签可用的最早时刻，等于interval_end|
|prediction、lower、upper|点预测及80%经验区间；历史不足时区间为空，不能宣称已校准|
|unit|负荷/PV为kW；价格为yuan/kWh|
|model|仅由开发期选定的模型身份|
|train_end|拟合所用标签的真实最晚完成时间；无拟合的朴素/官方模型为空|
|history_cutoff|月度拟合截止或无需拟合模型的历史访问截止，不等于每个日内特征的最新时刻|
|split|development或audit；audit是已知历史上的回顾性审计|

动态滞后特征和在线误差的访问截止由issue_time及各观测的完成时间共同控制。`candidate_predictions.csv`与`reports/forecast_evaluation_detail.csv`含实际标签，只能用于离线评分，禁止传给优化器作为未来输入。

`load_10min_adaptation.csv`和`price_10min_adaptation.csv`单独保留基线预测、修正量、漂移分数与最终修正预测。是否采用修正由开发期固定代理现金成本决定；不根据审计结果反复选择。

## 实验及模型重载

```bash
PYTHONPATH=src OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv/bin/python -m forecasting.experiment --run-id round01
```

运行ID不得复用。`runs/<run-id>/manifest.json`记录输入、配置、源码、环境和产物hash；`snapshot/`保留本轮源码。旧的根目录reports和predictions不被覆盖。

月度拟合模型位于`artifacts/models/<target>/<YYYY-MM>/<model>.joblib`，包含预处理流水线、特征列序、训练截止及是否预测PV残差。只能加载本项目可信产物。重载后按保存列序调用estimator.predict；PV残差加同次已发布raw_pv，然后将功率/当前非负价格预测截到0以上。当前价格支持域沿用附件非负价格，不宣称适用于负电价市场。

当前实验经济结果是固定执行器代理对比：统一2月1日6000kWh起步、连续传递SOC、固定alpha=0.70；不等同于要求1月启动与完整滚动求解的Q1-Q4最终成果。

次日零点时，前一计划日最后的00:00-00:10区间尚未完成。因此零点计划使用可见的末槽前电量、已确认合同与已发布净负荷预测，估算00:10初值；实际执行仍使用届时测得的真实电量。日志同时保留estimated_initial_energy_kwh与actual_initial_energy_kwh，禁止将后者提前交给零点规划。

仅评估器改变时，可以用`--reuse-forecast-run runs/<旧ID>`复用训练产物。程序要求数据、配置及data/features/models/backtest源码hash一致，复制后逐文件校验；仍在新目录重做全部预测证据、经济回放与开发期选择。旧运行即便在经济阶段中断，也不会被改写成已完成。
