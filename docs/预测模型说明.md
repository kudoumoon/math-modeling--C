# Q3/Q4 因果预测模型说明

## 预测对象

1. **负荷**：每天0:00预测该日144个十分钟区间；Q3滚动时点可在优化层利用当天已观测负荷做偏差修正。
2. **光伏**：不伪造第二套天气预报，而是以附件3在0/6/12/18点发布的未来24小时预报为基准，使用历史已结算误差做在线残差校准。
3. **价格**：Q4每天0:00预测该日144个十分钟价格。附件4是实际结算价格，只能作为训练标签和事后结算数据，不能在当天0:00直接输入优化器。

## 候选模型

- `seasonal_naive`：最近四个同星期值的中位数；
- `ridge`：对显式滞后、滚动统计和周期特征做正则化线性回归；
- `hist_gradient_boosting`：同一因果特征上的非线性树模型；
- 光伏另以 `raw_official` 为不可忽略的强基线，机器学习模型只预测其残差。

选型指标以开发期MAE为当前预测层准则；接入调度器后，应改用开发期因果回放现金成本作为主准则。复杂模型若没有降低下游成本，就回退到简单模型。

## 防泄漏设计

- 月度扩展窗口：月份 `m` 的预测器只用 `m` 月第一天之前已经完成的数据拟合；
- 所有滚动统计在日维度先 `shift(1)`；
- 前一数据行的最后区间实际属于当日 `0:00–0:10`，在当日0:00不可见，因此相应滞后特征显式置空；
- 光伏校准样本仅在该预报对应的六个十分钟实际区间全部结束后才可进入训练；
- 区间半径只由当前发布时刻之前已形成的历史预测残差计算；
- 每条输出同时保存 `issue_time`、`target_time`、`train_end` 和开发/审计标签。

## 运行

```bash
.venv/bin/python -m pytest -q
PYTHONPATH=src .venv/bin/python -m forecasting.cli
```

主要产物：

- `predictions/causal_forecasts.csv`：入选模型的点预测和80%经验区间；
- `reports/candidate_metrics.csv`：所有候选的开发/审计指标；
- `reports/selected_model_metrics.csv`：入选模型指标；
- `artifacts/selected_models.json`：仅由开发期确定的模型身份。

## 接入Q3/Q4优化器

- Q3 0:00使用负荷日前预测和0:00光伏校准预报；6/12/18点只替换尚未发生区间的光伏版本，并从实际SOC继续滚动优化。
- Q4-2使用负荷日前预测、可用的光伏信息口径和价格日前预测；Q4-3增加光伏滚动预报。实际价格仅进入执行后的现金账本。
- 风险余量应从各预测器自己的历史净负荷误差计算；不能把高分位预测与同一误差场景重复叠加。
