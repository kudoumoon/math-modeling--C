# 预测器双 Agent 验收规约 v1

冻结日期：2026-09-13。适用范围：本仓库预测层及固定调度代理中的预测价值验证。

用户要求 Agent1 优化、Agent2 独立审核，直到达到 90 分。100 分表示下列内部验收全部通过；国赛一等奖仅作为质量方向，没有官方的预测器百分制，内部得分不对应获奖概率。

## 循环与停止条件

1. Agent1 根据上一轮的问题单修改实现，固定本轮候选、配置和实验命令。
2. 保留旧结果，在独立运行目录生成预测、指标、输入/配置/源码哈希及环境记录。
3. Agent2 核对代码与原始实验产物，逐项给证据和分数；Agent1 不给自己放行。
4. 总分至少 90 且所有硬阻断清零才完成。否则按扣分项继续，不能提高自评分、删除失败实验或降低标准来达标。
5. 外部工具/数据阻断时如实记录，任务保持未完成；不声称对话结束后仍有后台进程工作。

## 实验纪律

- 保持原有月度扩展训练：每月模型只能使用月初已经完成的标签；2-6月开发，7-12月仅作回顾性披露。
- 首轮候选冻结为 seasonal_naive、ridge、hist_gradient_boosting；PV为 raw_official 及两个残差模型。首轮不进行超参数搜索，只修正确性及合法历史特征。
- 基线分别为负荷/价格 seasonal_naive、PV raw_official；统一时间键和可评分样本。缺少实际值仍须输出预测，只从评分中排除。
- 模型身份依开发期MAE选定。开发期选型结果用于同段评估带有选择偏差，必须标注；审计不能作为逐轮挑选模型的目标。
- 在线适配参数首轮维持现有默认值，先比较原预测与修正预测。收益不足时保留原模型，不以模型复杂度加分。
- 分别报告预测误差、区间质量及固定控制器代理成本。代理从2月1日6000kWh起连续运行，是预测通道比较实验，不是符合1月启动要求的最终国赛费用。
- 统计使用同日期配对差，固定种子20260912，连续3/7/14日块；不把小时样本当成独立日，PV重叠发布亦按日聚合后重采样。
